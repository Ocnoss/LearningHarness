# ADR-034：虚拟断言器（测试期真调模型产固定文本）+ 自动触发的**三重护栏**

- 日期：2026-09-21
- 状态：已采纳（**离线自测通过、闸门全绿；真调模型与自动触发待一次真会话验证**）
- 相关：ADR-033（断言器描述符形状、传递引擎）、ADR-015（model-tier：preset 能调 `ctx.llm`）、
  ARCHITECTURE §0.1 约束 5（preset 能拿 `ctx.llm`）/ 约束 9（环境变量惰性求值）、
  `lh-recorder-trace/index.js`（`isLearningSession` 判据与"append 失败不冒泡"的同构处理）

---

## 背景

ADR-033 定了断言器的**形状**与传递引擎，但引擎要跑起来，得有**第一个真实断言器**。
真实的学情断言器（判断掌握度、给 Claim）还没到做的时候——它需要证据格式、置信度协议（ARCHITECTURE §5 开放问题 1/2）。
但**传递链路**（叶子断言 → 逐层向上 → 到根停止）必须现在就能跑通、能观测，否则 ADR-033 只是纸面。

所以本次要一个**占位但真实**的断言器：它不做教学判断，只产出**确定形状**的一句断言，
把"自动触发 → 真调模型 → 写事件 → 递归上行"这条链验证出来。

同时，"自动触发 + 真调模型"会**花钱**、会**产噪声**——必须想清楚**什么时候不该触发**。

## 关键事实（查证过的，不是推断）

1. **preset 作用域能拿到 `ctx.llm` 并对 provider 发过真实调用**（ADR-015 / model-tier 实证，ARCHITECTURE §0.1 约束 5）。
   → 虚拟断言器"真调模型"这条路是通的，不是假设。
2. `@lh/model-tier/model` 的 `callModel({ llm, tier, messages, ... })` 返回 `{ ok, text, provider, model, degradation, ... }`；
   `textMessage({ text, pluginId, name })` 造一条带 `source.kind='plugin'` 的合成消息（**标明"这不是人类输入"**）。
3. **recorder-trace 踩过的污染事故**：开发对话若被当成学习行为写进 LH 日志，学习史就被污染。
   它的判据是 `isLearningSession`（`presetOfSession(session) === 'lh'`，取最后一条 `agent-preset/selected` 退回 header）。
4. 约束 9：环境变量**必须惰性求值**——写成模块级常量会在 import 时固化，"指到别处"的调用方被静默忽略。

## 决定

### 1. 虚拟断言器**真调模型**（flash 档）产固定上下文文本，而不是纯本地拼字符串

`assert()` 用 `textMessage` + `callModel({ llm, tier:'flash', messages, system, maxTokens:200, temperature:0 })`
发**固定提示词**，让模型原样输出一句：

> 「本次断言是在 {time}，位于第 {level} 级子课程「{title}」（路径：{path}），依据「{input摘要}」做出的断言，传递给第 {parentLevel} 层断言器。」

**为什么要真调**：验证"preset 作用域调 `ctx.llm` + `callModel` 形状"这条真实断言器的必经路，
纯本地拼串验不到它。用 `flash`（便宜档）+ `temperature:0`（稳定）把成本与随机性压到最低。

### 2. 模型不可用时**仍产出一句**（fallback 到本地模板），但可辨

`fromModel = res.ok===true && res.text` 非空；否则用同一个 `template()` 本地拼。
fallback 的 `confidence` 更低（0.2 vs 0.5）、`model` 字段为 **null**——审计时一眼能分辨"这句没经过模型"。
**理由**：断言器的天职是"产出断言"，真调模型是手段不是目的。若 flash 档暂时没配好就整条静默，
会让人**误判成传递逻辑坏了**（而逻辑其实是对的）。

### 3. 自动触发有**三重护栏**（挡住花钱与噪声）

| 护栏 | 判据 | 挡什么 |
|---|---|---|
| ① 仅学习会话 | `isLearningSession(session)`（照抄 recorder-trace） | 开发对话被断言、污染学习史 |
| ② 必须已 `enter_course` | `resolveNodeOfSession(tree, sessionId) !== null` | 没绑课程的闲聊——**天然噪声闸门** |
| ③ 环境开关 | `process.env.LH_ASSERTER === 'off'` 时整条静默（**惰性求值**） | 想临时全关（如跑别的验证、省钱） |

触发事件：`user/message`（对话输入，跳过 `source.kind` 非 user/unknown 的合成消息）
与 `tool/result`（**仅** `submit_answer`/`record_attempt` 这类"提交作答"工具，避免每个工具结果都断言）。

### 4. **异步、绝不抛**（旁路观测的纪律）

触发回调用 `void (async () => { …try/catch… })()` 包裹：模型调用、写事件、投影失败**只 trace，不冒泡**进宿主事件管线。
断言是旁路观测，坏了也不能弄坏学习者的会话（同 recorder-trace 的 append 失败处理、契约 §五之二）。

## 当时有哪些别的选择 / 为什么排除

| 别的选择 | 为什么排除 |
|---|---|
| **纯本地模板**（不调模型） | 验不到"preset 调 `ctx.llm` + `callModel`"这条真实断言器的必经路（关键事实 1 值得当场坐实） |
| **真调模型但无 fallback** | 模型档位没配好会让整条传递**静默**，误判成逻辑坏了。断言器天职是产出 |
| **手动触发**（工具调用才断言） | 需求是"用户输入**自动**产生断言并上行"；手动不符合，且拿不到"输入即证据"的自然语义 |
| **自动触发但无护栏** | 开发对话被断言、写进学习史（recorder-trace 踩过的污染事故）；且每条输入都白花一次模型调用 |
| **什么都不做**（等真实断言器） | 传递链路无法先跑通验证；真实断言器接入前**需要先有确定形状的产出**才能验递归 |

## 依赖什么前提 / 假设（前提塌了要重审）

1. **flash 档便宜**：测试期"每条绑定课程的输入 → 一串（叶→根）模型调用"的成本可接受。
2. **固定提示词 + `temperature:0` 能稳定产出那句文本**（模型偶尔改写由 fallback 兜底）。
3. **"已 `enter_course`"是有效噪声闸门**：没绑课程的会话不断言（护栏②）。
4. **`isLearningSession` 判据可靠**（照抄 recorder-trace，已在生产挡开发会话）。
5. **preset 作用域调模型可行**（关键事实 1，model-tier 已实证）。

## 怎么知道它错了（可观察信号，不是"感觉不对"）

| 失效信号 | 说明 / 处置 |
|---|---|
| **真会话里断言的 `model` 字段大量为 null**（fallback 占比高） | flash 档没配好/provider 限流 → 查 model-tier 档位解析；不是断言逻辑坏了 |
| **学习史里出现开发对话的断言** | 护栏① `isLearningSession` 失效 → 查 `index.js` L127-129、L300 |
| **未 `enter_course` 的会话产生了断言** | 护栏② 失效 → 查 `index.js` L313-317 |
| **每建会话/每条输入都白花模型调用，成本失控** | 触发条件太宽 → 收紧 `TRIGGER_TYPES`/`SUBMIT_TOOLS`，或 `LH_ASSERTER=off` 临时全关 |
| **断言器抛错导致学习者会话卡住** | 决定 4 的异步 try/catch 失效（异常冒泡进宿主）→ 查 `index.js` L306、L330-332 |
| **`LH_ASSERTER=off` 不生效** | 护栏③被写成模块级常量（约束 9）→ 必须在 `onSessionEvent` 内惰性读 |

## 验证（本次真做过，不是推算）

| 步骤 | 结果 |
|---|---|
| `node plugins/lh-asserter/selftest.mjs`（离线，**假 `call`** 不调真模型） | **42 通过 / 0 失败**：假 call 模型可用时校验提示词含标题/层级/输入/目标层级/路径；fallback 模板；target=null；call 抛错仍产出模板 |
| `node scripts/check-all.mjs` | 24 项：**23 绿 + 1 应然红（check-restart）+ 0 不该红** |

**待真会话验证（只能由学习者在重启 dsh 后做，AI 修不了这一步——这正是 check-restart 应然红的含义）**：
1. `create_course` 建「行测」→ 其下建「资料分析」（2 级）→ 再建子课程（3 级）；
2. `enter_course` 绑当前会话到 3 级节点；
3. 发一句用户输入 → 查 `data/events.jsonl` 出现 3 级 `lh/assertion/made`，并沿树向上产生 2 级、1 级断言
   （`derived_from` 串成链、`propagate_to` 逐级指父）；`model` 字段非 null（真调到了模型）；
4. 点侧栏「课程树」按钮开浮层：看到递归树、当前节点高亮、断言气泡沿边向上传递的动画（ADR 之外的 lh-course-ui）。

**证据位置**：
- `plugins/lh-asserter/asserters/virtual.js`：`assert` 真调 + fallback（L99-125）、`template`（L56-63）、`SYSTEM` 固定提示（L32-34）。
- `plugins/lh-asserter/index.js`：三重护栏 `onSessionEvent`（L294-334，③L296 / ①L300 / ②L313-317）、
  异步 `void (async…)`（L306）、`isLearningSession`（L127-129）、`extractInput` 跳过合成消息（L150-170）。
- 挂载：`.dsh/.agent-presets/lh/agent.cordis.yml` L141-149（`inject ['llm','sessions']`，不 provide root-realm 服务，故不需 isolate realm）。

## 没做的（如实记下）

- **真实学情断言器没做**：虚拟断言器只产固定文本、不判断掌握度。真实断言器需要证据格式与置信度协议（§5 开放问题 1/2）。
- **档位按层级配置没做**：现在所有断言器固定 `flash`。真实场景里高层综合断言可能需要更强档位（`balance`/`max`）。
- **`tool/result` 触发范围是临时答案**：默认只纳入 `submit_answer`/`record_attempt`（`SUBMIT_TOOLS`）。
  "做题类输入还有哪些工具该纳入"待真实使用后再调（列入 ADR-033 传递语义的开放边界）。
- **成本上限/限流没做**：护栏③只能全开/全关，没有"每会话每分钟最多 N 次断言"这类细粒度节流。若真会话验证发现成本失控，这是第一个要补的。
