# ADR-038：作答的「部分正确」与「作答者型号」

- **状态**：已实现（2026-10-13）
- **触发**：作者要求 ① 模型作答要带**型号**（以后让不同型号的模型都来试）② 结果状态加「部分正确」（应对将来的多选/简答，分数形如 6/12）③「来源」列改「作答者」④ 做题记录加「正确答案」列。
- **为什么写 ADR**：它**触到 ADR-018 决定 5 的冻结语义**（"判分三态 `true|false|null`"）与 ADR-017 决定 6 的作答事件字段形状。虽然本次是纯加法，但**一个既有聚合器的语义被改了**（见决定 3），符合 §4.3(a)"修订/触及已冻结决策"的记账要求。

---

## 决定 1：`correct` 三态**不动**，另加分数；「部分正确」是**派生判决**

作答事件的数据字段（`lh/user/attempt`）新增三个，都是可选（旧事件没有，语义不变）：

| 字段 | 含义 | 谁填 |
|---|---|---|
| `model` | **谁作的答**（如 `DeepSeek-v4.1`）。人作答为 `null` | 调用方 |
| `score_got` | 部分正确的得分（如 6） | 判分方 |
| `score_total` | 部分正确的满分（如 12） | 判分方 |

判决（**读取端词汇，不进日志**，ADR-014"可派生的不进日志"）：

```
correct === true                      → correct
correct === false && score_got > 0    → partial
correct === false                     → wrong
correct === null                      → unjudged
```

- **为什么不把 `correct` 改成数字**：那会让它"有时布尔、有时数字"，每个消费方都得先判类型——最容易写错、且看起来正常的形状。三态是"这件事判成什么"，分数是"判到什么程度"，两件事。
- **`score_got = 0` 不算 partial**：一分没得就是错（否则"0/12"会被当成"部分正确"，正确率分母被稀释）。
- **`model` 放 `data` 不放进 `provenance`**：`provenance` 问的是"谁写了这条事件"（题库插件），型号问的是"谁作的答"。导入事件（`questions-imported`）把 model 放 provenance，是因为那里"抽题的模型"与"写事件的插件"是同一件事的两个侧面；作答这里不是。
  - **失效信号**：若某工具按 `provenance.model` 找作答型号而找不到——那是它找错字段，**不要**把 model 挪进 provenance 去迁就它。
- **形状校验**：`score_got`/`score_total` 必须成对出现，且 `score_total > 0`、`0 ≤ score_got ≤ score_total`。违反者进 `malformed`（如实报出，**不**当成答错）。

## 决定 2：`model` 只对模型作答有意义，人作答显式写 `null`

理由同契约 §2.2：显式写 `null` 而不是省略，读取端才能区分"没有"与"没记"。这也让"作答者"这一列有确定语义：`null` + `source: human` = 人；有值 + `source: llm` = 某个模型。

## 决定 3（**这条改了既有语义，是本次最需要记的一条**）：`summarizeAttempts` 的 `wrong` 不再包含 partial

- 改前：`correct === false` → `wrong`。
- 改后：`partial`（即 `correct === false && score_got > 0`）**单列**，不进 `wrong`，**也不进正确率的分母**。

理由与 ADR-018 决定 5 里"判不了不能默认算错"完全同源：**答对一半不能默认算错**。把 6/12 算成错，会让学习者的正确率无故变低，而那种变低在数据里看不出来。

- **正确率口径不变**：仍是 `correct / (correct + wrong)`；partial 与 unjudged 一样在分母之外、单列计数。
- **"错题"判定也跟着改**：题目的"最近答错"用 `last_verdict === 'wrong'`，partial **不算错题**（错题本里不该混进"其实会了一半"的题）。
- **失效信号**：一旦有人要按分数算掌握度（把 6/12 折成半分、或按得分率排序），那就是**该改正确率口径**的时候——改口径要回来改本 ADR，**不要**在某个投影里偷偷加权。

## 决定 4：界面列（做题记录）

- 「来源」→ **「作答者」**：人作答显示"人"；模型作答显示**型号**（未记型号显示"模型（未记型号）"，不假装知道）；悬停给完整信息。
- 新增 **「正确答案」** 列：一律**字符型**（选择题 `A、C`、填空 `42`、将来简答整段文字，在这一列是同一件事）。
- 「结果」四态：**正确 / 部分正确 / 错误 / 判不了**；部分正确附分数（`部分正确 6/12`）。色只用圆点（令牌铁律）。
- 结果筛选从三态改为**四态**（新增 `verdict` 查询参数）；旧的 `correct`（三态原值）**保留**——两个问法都正当：一个问"人话判决"，一个问"三态原值"。

## 决定 5：会话坐标**不改**

作者明确：后续"让模型做题"也是通过会话呼出，所以会话索引逻辑不动；而本次这类模型作答不是会话要求的，继续如实写 **"无会话坐标"**（`session_ref: null`），不猜。

## 未做的事（如实）

- **没有**把"部分正确"接进正确率（见决定 3 的失效信号）。
- **没有**做"多个虚拟学习者"：要把不同模型的作答当成不同学习者看，还需要 `session_ref` 之外的一个学习者标识——那是更大的设计，本轮不做。
- **没有**写"模拟批次"标记（`simulated` / 批次 id）：留着与"模拟作答器 + 同题检测"一起做（作者已批准那两件）。
