## E8. 一行正则把 49 道题的解析全截成了第一行 —— 而它**不像坏了**

**会复发 / 反直觉 / 代价高**

`extract_answers.py` 里：

```python
RE_EXPLAIN = re.compile(r"【\s*实\s*战\s*解\s*析\s*】\s*([^\n【]*)")   # [^\n【]* 遇换行即停
```

资料是双栏 PDF，一行约 26 字，**于是每道题的解析都被截到第一行、截在句子中间**。

### 为什么半年都发现不了

- **它不报错、也不像坏的**：`analysis_available` 因为"非空"被置为 true，
  界面上就显示一段**像解析的残句**。作者的感受是"解析要么不完整要么没有"——
  那已经是**很克制的描述**了，实际是"真正能当讲解用的 0 道"。
- **它不像坏了，所以没人去量它**。修前：空 23 / 拼凑 3 / 疑似截断 23 / 完整 **0**。

### 定位它的关键证据不是"读代码"，是**长度是常数**

23 条被截断的解析**长度全是 26 字**。这不是"跨页切断"的随机长度，
而是**一行的宽度**。一个恒定的数字把矛头直接指向了"按行截取"。

→ **一般化：当一批坏数据的某个度量是常数时，去找"那个常数是从哪来的"，
比逐条读内容快得多。** 26 = 一行 = `[^\n]*`。

### 修法与度量

- 正则改为取到**下一个标记或块末尾**（`([\s\S]*?)(?=【|\Z)`）。
- 因为 `answer_text_full`（对齐报告里）没受这个 bug 影响，可以**不重跑流水线**就量化：
  884 → 13710 字（×15.5）。
- 入库用**打补丁**而不是重跑合并：只错一个字段就只改那个字段。
  补丁器带三条不变量（题目数、**id 一个不变**、其余字段逐字节不变），不满足就拒绝写盘。
  实测 49 道全部匹配，**每道都变长、无一变短**。
- 结果：完整可用 **0 → 34（69%）**，空解析 23 → 0。

### 一个必须如实标注的残留

补回来的正文是 **OCR 两栏串行**的（"题干中的对比实验明 未表明实验结果…应补充 显缺少实验结果"）。
所以 `analysis_kind` 标成 **`原文（OCR 可能串行）`**，而不是当干净原文。
**它适合给模型当证据，不适合原样端给学习者当讲义。**

## E9. `shell.overlay` 是 **root 作用域**，所以 `props.sessionId` 永远是 undefined

**会复发**

「AI深解」第一次跑，报的是"拿不到当前会话 id（插槽 props 里没有 sessionId）"。

根因不是宿主没给，是**我挑错了插槽**：`sessionId` 是**会话作用域**插槽的标准 props，
而刷题面板注册在 `shell.overlay` —— 那是 **root 作用域**的插槽
（面板要跨会话、浮在最上面，就只能挂那里）。**两者不可兼得，是我没意识到的约束。**

修法不是换插槽（换了就不再跨会话），而是**去问会话服务**：

```js
ctx.sessions.list.getSnapshot().current   // ISessions.list: ObservableSnapshot<SessionListState>
```

→ **一般化：插槽的 `scope` 决定了 props 里有什么。**
拿不到某个 props 时，先问"这个插槽是什么作用域"，而不是怀疑宿主没传。

**顺带白拿了一个功能**：`list` 是可订阅快照（`subscribe(fn)`），
所以"切换会话"的检测不需要轮询、也不需要猜间隔——订阅它就行（见下面的最小化）。

## E10. hook 写在提前 return 之后 → 面板永远打不开（本日第二次同款）

**代价高 / 只在运行时暴露**

给面板加 `panel_width` 判断时，把一个 `useEffect` 写在了 `if (!open) return null` **之后**。
面板关着跑 N 个 hook、打开跑 N+1 个 → React 抛
`Rendered more hooks than during the previous render` → **面板永远渲染不出来**。
作者刷新后看到的是"点了没反应"。

恶劣之处：**静态看每一行都对**（语法、类型、逻辑都合法），只在状态变化那一刻炸。

### 修法与防复发

- 规矩：**组件里所有 hook 都必须在第一个 return 之前，没有例外。**
- 判据交给测试，且**与 React 一致**：同一个组件在两种状态下的 **hook 调用次数必须相同**。
  - **数 hook，不扫源码**：我第一版扫源码找 `React.use*`，**漏了 `FallbackEntry`**
    —— 它用的是自定义 hook（`usePanelOpen`），不带 `React.` 前缀。
  - **判据本身也被验**：拿一个**故意写坏**的组件试它必须报警。
    否则那几条"通过"只是假绿。
- 今天这套判据**当场又救了一次**：加"收起成胶囊"时新增了一个提前 return，
  测试立刻覆盖了展开/收起两种状态的 hook 数（见 `selftest-client.mjs` 第 12 节）。
